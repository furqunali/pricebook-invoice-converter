Pricebook Invoice Convertor — how to use it

    

      
    
        
  1. API key. Paste any key into the Connection box and press Connect — the tool
            works out by itself whether it is a Claude key (sk-ant-...) or a Gemini key
            (AIza... / AQ...), loads the models that key can actually use, picks a
            working one and tests it. Claude keys come from console.anthropic.com → API Keys,
            Gemini keys from aistudio.google.com → API keys. Any other service
            (OpenAI, OpenRouter, Groq, DeepSeek, Mistral, xAI, or a server of your own) works too —
            choose Any other (OpenAI-compatible), put in the base URL your provider gives you, and
            press Connect. The key stays in this browser, and each provider keeps its own key.
            
    If anything fails, press Diagnostics — it prints exactly what went wrong and a
            Copy report button to send on. Model names change over time, so if one is rejected,
            press Load models and the tool will list exactly what your key can use.
    2. 
        
  2. Add files. Drag invoice PDFs or photos in, or click the box to browse.
            Files are read in the order you add them.
    3. 
        
  3. Join. If one invoice is spread over two files, press + join on the second file.
    4. 
        
  4. Convert. Each invoice appears as a card with its vendor, store, invoice number,
            date, total and every line item.
    5. 
        
  5. Check. A green OK badge means the line items add up to the invoice total.
            A red CHECK badge means something needs your attention — the reason is listed under the table.
            Fix anything directly in the card.
    6. 
        
  6. Download. Use Download .txt in the output bar. The file follows the exact import
            format, so you can upload it straight to the back office system.
    7. 
      

      
Clear all empties the files, invoices and output but keeps your API key.
         Reset app wipes everything including the saved key and settings, like opening the tool for the first time.

      
Sharing. Keep this file in Google Drive, but each person must download it first and open it
         in Chrome or Edge. HTML files do not run inside the Drive preview window.

      
Free keys. Google AI Studio gives a free Gemini key on a normal Google account:
         aistudio.google.com → API keys → Create API key. It takes about a minute and
         needs no card. That is the quickest way for a teammate to get going. The free tier has daily
         limits, so for heavy days a paid key is steadier.

      
One key for the whole team. Whoever looks after this file can paste one company key into the
         BUILT_IN line near the bottom of the file, in a text editor. Everyone who opens that copy
         is then connected with no setup at all. Keep a spending limit on that key, since anyone holding the
         file can read it.

      
Simple and Advanced views. Simple view shows only what is needed: add files, convert, check,
         download. Advanced view adds the provider, model, reading options, token usage and the activity log.

      
PDFs on other providers. Claude and Gemini read PDFs directly. OpenAI-compatible services
         only take images, so the tool turns each PDF page into a picture first — that needs an internet
         connection the first time you use it, and only the first 15 pages of a file are sent.

      
Very large invoices. If a bill has hundreds of lines, the tool automatically reads it again
         with a bigger budget. If it is still too long, whatever was read is kept and flagged, so split that
         PDF into two halves and convert them separately.

      
Always check the badges before downloading. The tool reads the invoice and then adds up
         every line against the printed total, so mistakes show up as a red badge instead of slipping into the file.
